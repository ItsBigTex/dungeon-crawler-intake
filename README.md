# Dungeon System — Crawler Intake

Ready for GitHub Pages.

1. Create a GitHub repository.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, `main`, `/ (root)`.
5. Save and share the URL GitHub provides.

Player answers remain in their own browser unless they Print / Save as PDF and send the result to the GM.
